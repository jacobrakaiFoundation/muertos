Linux for business

Enterprise Linux 7 reached end of life. Your servers did not.

muertōs is a maintained continuation of the 7.9 release: the frozen package tree, plus rebuilt packages carrying security fixes. It is binary compatible with CentOS 7, for the systems that cannot move yet.

Scope

Security fixes, nothing else

The base stays where your applications expect it. Changes are backported security patches, not new versions.

  • Base: 7.9.2009 os, updates and extras
  • x86_64 only
  • No version bumps unless no patch can be backported

Kernel

A kernel that still gets fixes

The plan is a 6.12 long-term kernel, packaged as kernel-lt, with the stock 3.10 kernel frozen beside it.

  • Rebuilt from kernel.org stable releases
  • Installed and boot-tested on a stock 7.9 virtual machine in CI
  • Out-of-tree kernel modules need a rebuild

Provenance

You can see what changed

Every package starts from a signature-checked source package from the public vault, and every patch is in the repository.

  • Rebuilt packages carry .muertos in their release tag
  • Releases will be signed with a hardware-held OpenPGP key
  • Build scripts and patches are public

Running 7 in production and want to follow along?

The work happens in the open. Watch the repository for the first published packages, or open an issue to say which packages your systems depend on. That helps decide what gets fixed first.
